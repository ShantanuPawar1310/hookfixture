# Changelog

## 0.1.0 — 2026-11-26

Initial alpha:

- Deterministic event IDs and timestamps, with optional explicit values.
- Duplicate, reverse-order and seeded shuffled delivery scenarios.
- JSON manifests with exact file checksums and duplicate-payload validation.
- Local Python API and CLI, with no runtime dependencies or network operations.
- Synthetic invoice fixtures and an idempotent consumer example.
- Unit and CLI tests, CI configuration, contributor guide and MIT license.

This release begins the project's history. No prior users, downloads or downstream
dependents are claimed.
